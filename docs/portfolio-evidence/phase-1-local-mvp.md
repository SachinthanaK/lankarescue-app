# Phase 1 Local MVP Evidence

Date: 2026-08-20  
Capability: **Implemented and tested locally**

## Delivered

- compact mobile-first Next.js 16 PWA shell with an English localization boundary;
- citizen relief-request submission and secure request tracking;
- public request references paired with separate high-entropy private tokens;
- SHA-256 token hashes only in the repository; plaintext tokens are never persisted or logged;
- local-only staff queue, gated by environment and feature flag;
- FastAPI skeletons for Incident API, Alert Ingestor, Resource Matcher, and Notification Worker;
- shared JSON logging, correlation IDs, liveness, readiness, metadata, security, and event-envelope libraries;
- repository interface with an in-memory Phase 1 adapter;
- deterministic mock alert provider;
- OpenAPI documentation generated by FastAPI;
- local setup, run, and verification scripts.

## Security boundaries

- Tracking requires both the reference and the private token.
- Tracking tokens are submitted in a JSON body, not a URL or query string.
- Citizen tracking responses exclude contact details.
- The unauthenticated staff demo returns 404 unless `APP_ENV=local` and `ENABLE_DEMO_STAFF=true`.
- This phase is not deployed and must not process real emergency or personal data.

## Intentional Phase 1 limitations

- in-memory storage with no restart durability;
- English UI only, with Sinhala and Tamil content deferred;
- no staff identity, cloud services, queues, notifications, containers, or Kubernetes;
- no real alert provider or official emergency-service integration.
