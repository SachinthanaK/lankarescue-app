# Portfolio Evidence Index

Every phase preserves safe evidence: diagrams, commands, screenshots, recordings, reports, dashboards, traces, alerts, rollback timelines, restore results, Backstage flows, and CLI output.

Rules:

- Use synthetic/redacted data.
- Do not expose subscription/tenant identifiers, credentials, tracking tokens, contact data, private endpoints, or sensitive DLQ payloads.
- Link evidence to the phase, issue/PR, commit, environment, date, verification, and capability label.
- Prefer source-controlled exports and text reports over screenshots where useful.
