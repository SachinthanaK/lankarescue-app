# Lightweight Phase Gate

```text
Goal achieved?
Verification passed?
Exit criteria satisfied?
Portfolio evidence captured and safely redacted?
Actual cost versus budget acceptable?
Security findings resolved or explicitly accepted?
Proceed, correct, or defer?
```

The gate is an evidence checklist in an issue or pull request, not a separate bureaucracy. External accounts, billable resources, destructive operations, shared/public load tests, and every Phase 17 option require explicit additional approval.
