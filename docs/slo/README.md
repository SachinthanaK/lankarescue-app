# SLO Documentation

Initial values are portfolio targets until measurable SLIs and test evidence exist:

- API availability: 99.9%.
- API p95 latency: below 500 ms.
- Critical notification processing: 95% within 30 seconds.
- Unhandled processing failures: below 0.1%.

This directory will hold measurement definitions, windows, exclusions, error-budget policy, dashboards, and actual status. These are not enterprise SLAs.
