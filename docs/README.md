# LankaRescue Documentation

| Area | Purpose |
|---|---|
| `architecture/` | System, container, event, delivery, and environment designs |
| `adr/` | Immutable architectural decision records |
| `standards/` | Naming, Git, quality, and completion conventions |
| `security/` | Threat model, data handling, identity, and authorization |
| `runbooks/` | Actionable operational response procedures |
| `slo/` | SLIs, portfolio targets, and error-budget policy |
| `recovery/` | Restore/DR plans and actual test reports |
| `costs/` | Minimal, full-demo, and enterprise-reference cost models |
| `experiments/` | Reliability experiment plans and evidence |
| `postmortems/` | Blameless incident learning records |
| `portfolio-evidence/` | Safe screenshots, outputs, diagrams, and demo index |
| `backlog/` | Prioritized delivery roadmap and phase gates |

Documentation uses the capability labels `Implemented`, `Tested`, `Reference architecture`, and `Future enhancement`. Claims must not exceed retained evidence.
