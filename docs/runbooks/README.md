# Runbooks

Runbooks are introduced with operational capabilities. Each actionable alert must link to a runbook containing symptoms, impact, dashboards/queries, safe checks, mitigation, recovery verification, owner, and escalation.

Planned runbooks include high API latency/error rate, Service Bus backlog, DLQ messages, outbox backlog, PostgreSQL unavailable/connections, worker failure, Flux reconciliation, and identity/Key Vault failure.
